# MoFi

## Overview
MoFi's SourcePoint line, designed by Andrew Jones, uses a concentric 1.25 in soft dome in a paper-cone woofer with a 1.6 kHz crossover ([mfr-mofi-sourcepoint-8](../sources/mfr-mofi-sourcepoint-8.md)). Only the SourcePoint 8 (8 in coax, 456 mm tall, $2,195 per pair) fits bookshelf limits. Erin's Audio Corner measured ±1.3 dB listening window and f3 of 52 Hz ([eac-mofi-sourcepoint-8](../sources/eac-mofi-sourcepoint-8.md), Tier A); Stereophile also measured it ([stereophile-mofi-sourcepoint-8](../sources/stereophile-mofi-sourcepoint-8.md)).

## Patterns
One paged model. Its 8.0 Ω minimum equals the rating, so no impedance flag; measured sensitivity is 85.9 dB against 87.0 dB claimed (1.1 dB short). Critics ([stereophile-review-mofi-sourcepoint-8](../sources/stereophile-review-mofi-sourcepoint-8.md), [futureaudiophile-mofi-sourcepoint-8](../sources/futureaudiophile-mofi-sourcepoint-8.md)) call it balanced and non-fatiguing, with little output below 50 Hz. [users-mofi-sourcepoint-8](../sources/users-mofi-sourcepoint-8.md) has only 2 owner reports, anecdotal. Both screened siblings fail on size.
