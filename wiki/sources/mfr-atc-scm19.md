# Manufacturer: ATC SCM19

## Summary
ATC lists the SCM19 in its current Entry Series (passive, 8 Ω). Page does not use the word "standmount" but the 438 mm cabinet is a stand-mount size. US price is not on the maker site; US dealers list it.

## Specs (claimed)
| Field | Value |
|---|---|
| Nominal impedance | 8 Ω |
| Sensitivity | 85 dB @ 1 W / 1 m; at an 8 Ω nominal load 1 W = 2.83 V, so 85.0 dB @ 2.83 V (no conversion offset applied) |
| Claimed FR | 54 Hz-22 kHz (-6 dB) |
| Matched response | ±0.5 dB (pair matching) |
| Max SPL | 108 dB |
| Crossover | 2.5 kHz |
| Drivers | 150 mm "SL" mid/bass with 75 mm integral soft dome; 25 mm soft-dome tweeter with alloy waveguide |
| Enclosure | sealed (per reviews [tas-atc-scm19](tas-atc-scm19.md), [stereotimes-atc-scm19](stereotimes-atc-scm19.md)) |
| Recommended amp | 75-300 W |
| Dimensions | 438 x 265 x 300 mm (grille adds 34 mm depth) |
| Weight | 17.8 kg each |
