# napilopez: Polk R200 measurements (2021-05-17)

## Summary
Hobbyist spinorama of the R200 ($700 then) posted to ASR. He found the listening window very flat, better than Polk's Legend L200, with solid horizontals, heavy tweeter beaming above 5 kHz (so aiming-sensitive) and a 4.5 kHz on-axis diffraction dip. Raw dump is REW text format; no metrics were computed from it.

## Extracted values
| Field | Value | Note |
|---|---|---|
| Preference score | 6.16 / 8.23 (no sub / sub) | per spinorama.org packet data |
| Listening window | "very flat", ~Genelec-like | qualitative; graphs not read |
| Port | free of the L200's midrange port resonances | attributed |
| HF directivity | beams heavily after 5 kHz | attributed |

## Method notes
Home measurement rig with many-angle spinorama (same measurer as the TNW review, [tnw-polk-audio-reserve-r200](tnw-polk-audio-reserve-r200.md)); not Klippel NFS. Tier B.

## Reliability notes
Single sample. Pref score 6.16 is 1.1 higher than EAC's 5.09 for the same model; different rig and sample, treated as conflict, not averaged.
