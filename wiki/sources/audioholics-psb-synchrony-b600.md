# Audioholics: PSB Synchrony B600 review (2023-05-01)

## Summary
Gated spinorama-style measurements plus ground-plane bass. Larson finds good tonal accuracy, flat directivity indexes, usable bass to about 40 Hz and an impedance that "should really just be considered" 4 Ω. Performance 4.5/5, value 4.5/5 at $2,800/pair.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity | 87.2 dB, 2.83 V/1 m | stated |
| min impedance | about 4 Ω near 200 Hz (stated); curve reads about 4.5 Ω | graph-read (approx.) |
| Port tuning | about 45 Hz | stated from impedance graph |

## Method notes
Free-air at 7.5 ft height, 1 m, gated at 11 ms (resolution lost below 250 Hz, accuracy lost below 110 Hz), 1/24-octave smoothing; ground-plane measurement for bass. Measured with tweeter as reference axis.

## Reliability notes
Gated measurement, so lower confidence below about 250 Hz; bass from ground-plane. Unit supplied for review. Sensitivity differs from NRC by 1.5 dB.
