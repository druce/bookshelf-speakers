# Specs and pricing: Monitor Audio Apex A10

## Summary
Monitor Audio's own page (monitoraudio.com/en/product-ranges/apex/apex-a10) was seen only as a search excerpt, and scripted/WebFetch requests to it returned 404. Specs below come from Hifiverse (raw/manufacturer/mfr-monitor-audio-apex-a10-hifiverse.md) and agree with that excerpt. The A10 is sold singly.

## Specs (claimed)
| Field | Value |
|---|---|
| Nominal impedance | 8 Ω |
| Sensitivity | 87 dB (1 W / 1 m); at 8 Ω nominal this equals 87 dB at 2.83 V |
| Claimed FR | 60 Hz-35 kHz (±3 dB per Hifiverse) |
| Max SPL | 110.8 dBA (per Monitor Audio excerpt; claimed) |
| Drivers | 5.5" (140 mm) C-CAM bass/mid, 1" C-CAM gold dome tweeter |
| Crossover | 3 kHz |
| Port | front-mounted HiVe II reflex |
| Dimensions | 250 x 140 x 140 mm (HxWxD), aluminium cabinet |
| Weight | 3.95 kg each |
| Power | 25-100 W recommended |
