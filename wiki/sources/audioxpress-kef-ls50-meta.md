# audioXpress: KEF LS50 Meta measurements (2021-06-30)

## Summary
Klippel NFS measurement at Warkwyn (1800 points) with the port plugged (as received). Smooth on-axis 135 Hz-3 kHz, a 2 dB dip 1-3.5 kHz, a ~3 dB rise 3.5-10 kHz, good dispersion to 30°. Opening the port adds about 1 dB at 140 Hz and 1-2 dB around 40 Hz.

## Extracted values
| Field | Value | Note |
|---|---|---|
| FR character | ~2 dB dip 1-3.5 kHz, +3 dB rise 3.5-10 kHz | stated, port plugged |
| Port effect | +1 dB @ 140 Hz; ~1-2 dB gain near 40 Hz | stated |
| pref_score | 4.96 / 8.09 with sub | spinorama.org digitised data (differs from Klippel exports) |

## Method notes
Port plugged by default; data digitised on spinorama.org so no computed metrics here.

## Reliability notes
Port-plugged configuration is not the default-open setup used by ASR/EAC; treat comparisons with care. Magazine, single sample.
