# HomeTheaterHiFi: Fluance XL8 system incl. XL8S (Taps Das)

## Summary
Package review of the XL8F towers, XL8S bookshelves and XL8C centre. The XL8S were used as surrounds and, with a subwoofer, as stereo mains. Reviewer praises value and clarity; bookshelves lack deep bass.

## Key claims
- XL8S midrange described as lush, highs crisp and detailed, soundstage wide; "like much more expensive speakers".
- Not bass monsters; limited bottom end for the size, a sub is a boon.
- Cabinet well made; holds up at loud levels (reviewer's impression).
- Recommends the package as a "steal"; no listed dislikes.

## Method notes
Listening only, no measurements; Cambridge CXA61 and Marantz SR6009; Q Acoustics QB12 sub on the bookshelves.

## Reliability notes
Manufacturer-supplied sample; system review where XL8S gets limited space.
