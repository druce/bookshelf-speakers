# Hi-Fi News lab report: Focal Kanta N°1

## Summary
Hi-Fi News measured 87 dB sensitivity (below Focal's 88 dB), a 3.8 Ω minimum with EPDR never below 2 Ω, a mild "BBC dip" in the presence region, and 48 Hz bass extension (-6 dB re 200 Hz). Publication date is not on the saved page.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity_db_2v83 | 87.7 / 87.2 / 86.7 dB (mean / IEC / music) | stated; reviewer concludes 87 dB |
| min_impedance_ohm | 3.8 Ω @ 201 Hz | stated; max 32.5 Ω @ 5.2 Hz |
| epdr_min_ohm | 2.0 Ω @ 20 Hz | stated; also 2.1 Ω @ 134 Hz, 2.2 Ω @ 358 Hz |
| impedance phase | -51 deg @ 98 Hz to +50 deg @ 29 Hz | stated |
| response error 200 Hz-20 kHz | ±3.3 / ±3.5 dB (tweeter axis, two samples); within ±2 dB below 16 kHz | stated; about 2 dB dip 1.3-8 kHz, treble rise above 16 kHz |
| pair matching | ±0.9 dB | stated |
| f6_hz | 48 Hz (-6 dB re 200 Hz); 87 Hz with port bung | stated, diffraction-corrected nearfield |
| thd | 0.9% @ 100 Hz, 0.2% @ 1 kHz, 0.1% @ 10 kHz at 90 dB SPL/1 m | stated |
| CSD | treble resonance activity from bass-mid cone breakup | qualitative |

## Method notes
1 m on tweeter axis (not a full spin); nearfield diffraction-corrected bass. Not a Klippel spinorama, so directivity metrics are absent.

## Reliability notes
Two-sample pair; UK lab; tweeter-axis only. Tier B.
