# spinorama.org: Paradigm Millenia LP 2

## Summary
spinorama.org processing of the hobbyist data in [asr-paradigm-millenia-lp-2](asr-paradigm-millenia-lp-2.md) (36 horizontal + 36 vertical measurements, data quality rated "medium"). Gives sensitivity, bass extension and Olive-style preference score.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity_db_2v83 | 86.5 dB | measured, avg 300 Hz-3 kHz at 2.83 V / 1 m (spinorama.org statement) |
| f3_hz | 151 Hz | vs reference level; free-field |
| f6_hz | 127 Hz | |
| frequency deviation | 3.2 dB | over 300 Hz-5 kHz (not the 300 Hz-10 kHz window used on this wiki) |
| pref_score | 1.0 | no sub |
| pref_score_sub | 5.1 | perfect sub |
| pref score with EQ | 2.5 (6.2 with sub) | spinorama.org auto-EQ |

## Method notes
Computed by spinorama.org, not by scripts/cta2034.py. The ASR thread also quotes an earlier run of 0.3 (4.4 with sub), so the score depends on the version of the computation. Differences below 0.5 are not meaningful.

## Reliability notes
Derived from a single hobbyist, gated + near-field splice; low-frequency values (f3, preference-score bass terms) are less certain than mid/high data. Free-field, so not representative of wall placement.
