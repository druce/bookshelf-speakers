# SoundStage!/NRC: B&W 805 D4 Signature measurements

## Summary
Anechoic NRC measurements accompanying the SoundStage! Ultra review. Sensitivity is 84.1 dB (300 Hz-3 kHz listening window). The listening window has the same dished shape as the standard 805 D4 with a broad treble peak near 9-10 kHz; impedance minimum is about 4.5 Ω.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity_db_2v83 | 84.1 dB | stated, 300 Hz-3 kHz listening window, 2.83 V/1 m |
| min_impedance_ohm | ~4.5 Ω, flat 4.4-4.6 Ω from about 150 to 250 Hz and near 45 Hz | graph-read (approx.) |
| impedance peaks | ~35 Ω @ 27 Hz, ~45 Ω @ 80 Hz, ~35 Ω @ 1.9 kHz | graph-read (approx.) |
| THD+N at 90 dB (2 m) | ~1.8% near 100 Hz, below ~0.6% from 300 Hz to 5 kHz, ~1% near 7-8 kHz | graph-read (approx.); THD+N includes noise |
| listening window | ~88 dB at 100 Hz, 83-84 dB from 500 Hz-2 kHz, ~91.5 dB peak near 9-10 kHz | graph-read (approx.) |
| f3 / f6 | not stated | not estimated |

## Method notes
NRC anechoic chamber, microphone between woofer and tweeter, grille off, measured at 2 m and plotted at 1 m; THD at 90 dB SPL.

## Reliability notes
Single sample from B&W; published with the review. Graph-read values are approximate; THD is at 90 dB, so frontmatter THD stays null.
