# Stereophile: SourcePoint 8 measurements (2023-08-17)

## Summary
Atkinson's sidebar: sensitivity matches the 87 dB spec, impedance stays high (8 Ω nominal, min 7.47 Ω), the load is easy for amplifiers, and the response is even with a slight upper-mid and >9 kHz excess. He calls the measured performance excellent.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity | ~87 dB / 2.83 V / m | B-weighted estimate; same as spec |
| min_impedance_ohm | 7.47 Ω @ 120 Hz | stated; DATS V2 |
| epdr_min_ohm | 3.83 Ω @ 242 Hz | stated; EPDR below 4 Ω only between 197 and 341 Hz |
| response | even on tweeter axis, 30° horizontal average; slight excess in upper mids and above 9 kHz; small peak just above 3 kHz | text only; no f3 or deviation figures |
| port tuning | just above 50 Hz, two rear ports | reflex alignment described as maximally flat |
| enclosure modes | 410 Hz (top and sides), 359 Hz (sides), 355 Hz (back); low level, high Q | accelerometer |

## Method notes
DRA Labs MLSSA, DPA 4006 mic for farfield at 50", Earthworks QTC-40 nearfield; grille off. Quasi-anechoic, so less reliable below ~300 Hz.

## Reliability notes
Single sample supplied for the Kalman Rubinson review. No numeric LW deviation or f3, so only impedance/EPDR/sensitivity are entered.
