# Sound & Vision: Revel Concerta2 M16 test bench

## Summary
Lab test-bench sidebar (quasi-anechoic with close-miked woofer) for the Concerta2 system including the M16. Gives sensitivity, listening-window tolerance, f3/f6 and impedance minimum. Publication date was not captured. Only the test bench was fetched, not the full review text.

## Extracted values
| Field | Value | Note |
|---|---|---|
| sensitivity | 85.5 dB, 500 Hz-2 kHz (2.83 V/1 m) | measured, grilles on |
| listening window | +0.73 / -2.33 dB, 200 Hz-10 kHz | five-point average (axial, ±15° H/V); not directly comparable to CTA-2034 LW |
| f3 / f6 | 57 Hz / 50 Hz | close-miked woofer, quasi-anechoic |
| min impedance | 5.05 Ω @ 160 Hz | measured |
| phase angle | -41.5° @ 96 Hz | measured |

## Method notes
Quasi-anechoic at 1 m, grille on, 2.83 V input, woofer close-miked for LF splice.
