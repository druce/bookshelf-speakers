# Manufacturer: Audio Craftsmen Victoria

## Summary
Canadian direct-sale brand. Page shows the Victoria at $3,990 per pair, all inclusive, with an "Out of stock" label. A separate maker spec sheet PDF (https://www.pahmeraudio.com/_files/ugd/a744c0_1f94432d7a52499197a89dddafa29e2e.pdf, read but not saved to raw) gives dimensions and weight.

## Specs (claimed)
| Field | Value |
|---|---|
| Nominal impedance | 8 Ω |
| Sensitivity | 88 dB "efficiency"; basis (1 W vs 2.83 V) not stated, so treated as 88 dB @ 2.83 V for an 8 Ω load |
| Claimed FR | 42 Hz-25 kHz ±2 dB (claimed, no measurement) |
| Crossover | 2.2 kHz |
| Drivers | SEAS 180 mm (6.5" class) Nextel-coated mid/bass; SEAS 29 mm Crescendo soft-dome tweeter |
| Enclosure | double-walled, rear-ported |
| Recommended amp | 25-125 W |
| Dimensions | 405 x 230 x 355 mm (16 x 9 x 14 in) |
| Weight | 16 kg each |

## Price / status evidence
$3,990 per pair on the maker-direct page, marked Out of stock; the maker's all-products listing page does not include the Victoria (checked 2026-10-11). Stereophile reported $5,500 (CES 2016) and $5,999 (AXPONA 2023) earlier. Stock/continuation unclear; no third-party dealer found.

## Reliability notes
Claims only; measured sensitivity is about 4 dB below the claim ([eac-audio-craftsmen-victoria](eac-audio-craftsmen-victoria.md)).
